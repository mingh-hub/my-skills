# 输出与报告模板

本文件收录调研规划的三类输出模板与质量检测的报告模板。落盘目录一律为技能根 `reports/`，命名规则见文末。

**调研规划：开题默认长报告；续写、改写默认短版。** 用户说「展开/详细报告/完整分析」时才用长版。

---

## 输出 1：开题——长报告（默认）

开题调研默认输出完整报告。言情类型用「双主角关系发展主线」；古代/悬疑/科幻等类型可替换为「核心人物/主线发展」（如侦探与案件线、主角与对手线等）。

```markdown
# [书名/暂定名] 开题调研报告

## 创作目标与主题陈述
- 核心主题：
- 情绪基调：
- 目标受众与篇幅预期：
- 结局走向（HE/BE/开放式）：

## 核心主线发展（按阶段）（言情：双主角关系发展主线）
- 阶段一（开局/邂逅）：
- 阶段二（推进/试探）：
- 阶段三（升温/回撤）：
- 阶段四（危机/临界）：
- 阶段五（确认/结局）：

## 分幕式总体大纲（关键情节点）
- 第一幕：
- 第二幕：
- 第三幕：

## 时间线草图（里程碑事件）
- 事件1（时间/场景）：
- 事件2：
- …

## 人物特征草图（可映射到 characters）（言情：男主/女主；其他类型：主角/对手或核心人物）
- 主角/男主：目标/缺陷/弧光要点
- 对手/女主：防线/需求/弧光要点
- 重要配角（若有）：

## 风险与待确认项
- 待用户确认或下一轮追问入口：
```

## 输出 2：续写——短版（默认）

续写调研**默认用此短版**。每章只给「标题 + 200-300 字内容介绍」。

```markdown
# [项目名] 后续章节梳理

## 我的判断（最多 3 条）
1. 
2. 
3. 

## 建议方向
（1 条主路线，1-2 句）

## 章节简版方案

### 第 X 章《标题》
（200-300 字：本章讲什么、核心事件、情绪落点、与前后章衔接）

### 第 X+1 章《标题》
（同上）

### …

---
如需展开成完整报告，请说「展开」。
```

## 输出 4：续写 / 改写——长版（仅当用户说「展开」时）

用户明确说「展开/详细报告/完整分析」时使用。

- **续写长版**可含：当前阶段诊断、多路线对比表、推荐路线、未来 3-5 章可写粒度、节奏与冲突建议。
- **改写长版**可含：问题清单、原因拆解、保守/平衡/激进三档方案、推荐方案与改动要点、验收清单。

落盘时按对应场景命名：续写策略报告、改写策略报告。

## 输出 5：质量检测——QA 报告

```markdown
# QA 报告：《小说名》第 X 章

**检查日期**：YYYY-MM-DD
**检查范围**：第 X 章 / 全文
**参考设定**：characters.md, timeline.md, outline.md, spaces.md（novel-creator 项目含空间布置；或「无」）

## 缺陷清单

### BLOCKER（致命）
| 编号 | 维度 | 问题描述 | 位置 | 状态 |
|------|------|----------|------|------|
| QA-001 | 时间线一致性 | 第5章写张三2003年大学毕业，但第8章变成2005年 | 第8章第3段 | OPEN |

### CRITICAL（严重）
（无则省略）

### MAJOR（一般）
（无则省略）

### MINOR（轻微）
（无则省略）

## 统计
- 致命：X 个
- 严重：X 个
- 一般：X 个
- 轻微：X 个
- 总计：X 个
```

## 报告命名与落盘

- 落盘目录：技能根 `reports/`。
- 调研报告：
  - 开题：`[书名或项目名]-开题调研报告-[YYYYMMDD].md`
  - 续写：`[书名或项目名]-续写策略报告-[YYYYMMDD].md`
  - 改写：`[书名或项目名]-改写策略报告-[YYYYMMDD].md`
- QA 报告：`[项目名]-[YYYYMMDD].md`（如 `ganxiang-20260209.md`、`standalone-20260209.md`）。
- 调研的续写/改写/章节快线**默认不落盘**，仅在用户明确要求保存时写入 `reports/`。
